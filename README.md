Online Examination System

This project is a simple Online Examination System developed using Java Swing as part of a Java programming assignment. It provides a graphical interface where students can enter their details, attend a multiple-choice examination, and view their results at the end.

* Features:
Student details collection
10 Multiple Choice Questions
JRadioButton options
Previous and Next navigation
60-second countdown timer
Automatic submission when time expires
Score calculation
Correct, wrong and unanswered count
Percentage calculation
Pass/Fail result

* Technologies Used:
Java
Java Swing
ArrayList

* Project Files:
1. OnlineExam.java
Contains the main program, graphical user interface, examination logic, timer, navigation, and result calculation.

2. Question.java
Contains the Question class used to store the question text, options, and correct answer.

* Output Screenshots:

* How to Run:
1.Compile the program using:   javac Question.java OnlineExam.java
2.Run the program using:   java OnlineExam

The application will open with the start screen, where the student can enter their details and begin the examination.
